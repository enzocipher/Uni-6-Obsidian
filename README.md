# Uni 6 Obsidian

Vault de estudio **The CISO Path**, organizado por cursos del sexto ciclo.

## Abrir en Obsidian

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/enzocipher/Uni-6-Obsidian.git
   ```

2. En Obsidian, elegir **Abrir carpeta como bóveda** y seleccionar la carpeta clonada.
3. Abrir [Índice de cursos](Índice%20de%20cursos.md) para comenzar.

## Contenido

- Arquitectura de Ciberseguridad.
- Procesos de Ciberseguridad.
- Seguridad de Integración de Aplicaciones.
- Ciberseguridad en Entornos Industriales y Cloud.
- Seguridad de la Información.

El vault contiene 31 notas de clase, dos notas de práctica, cinco índices de curso, el índice general, `Conexiones.canvas` e `Indishe.base`. Los títulos utilizan espacios y las propiedades conservan el orden de unidad y sesión. Las notas incluyen enlaces a sus fuentes del aula virtual, que requieren acceso a UPC.

## Configuración incluida

La carpeta `.obsidian` conserva la configuración del vault, el tema **Aurora** y los cuatro plugins comunitarios instalados:

- Linter (`obsidian-linter`).
- Importer (`obsidian-importer`).
- Better Export PDF (`better-export-pdf`).
- Mehrmaid (`mehrmaid`).

Se incluyen los archivos de los plugins y su configuración disponible. Obsidian puede solicitar confirmar la confianza en el vault para habilitar plugins comunitarios al abrirlo en otro equipo.

## Actualizar con Git

Para descargar cambios:

```bash
git pull
```

Para guardar y subir cambios propios:

```bash
git add .
git commit -m "Actualizar apuntes"
git push
```
